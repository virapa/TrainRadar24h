# TrainRadar24h · web

PWA de TrainRadar24h: React 19, TypeScript, Vite y MapLibre GL.

```bash
npm install
npm test        # pruebas (Vitest)
npm run lint    # oxlint
npm run dev     # http://localhost:5180, reenvía /api a http://localhost:8090 (o a $API_URL)
npm run build   # versión de producción en dist/
```

Consulta el [README principal](../README.md) para la arquitectura, el despliegue con Docker y la configuración.
